# Student Exam Score Analysis

This project explores a **Student Exam Score** dataset to understand the factors associated with student academic performance.

## Objective

The main objective is to analyze student-related data, identify patterns affecting exam scores, and present meaningful insights using data analysis and visualization techniques.

## Project Workflow

- Loaded and explored the dataset
- Checked data types and missing values
- Cleaned and prepared the data for analysis
- Performed Exploratory Data Analysis (EDA)
- Examined relationships between student characteristics and exam scores
- Created visualizations to identify trends and patterns
- Summarized key observations from the analysis

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Analysis Areas

The analysis focuses on understanding how available student-related variables are associated with **exam performance and score variation**.

Visualizations are used to make the patterns and relationships easier to understand.
